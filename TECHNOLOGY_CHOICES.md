# Technology Choices

## 1. MERN Stack

**Technologies:** MongoDB, Express.js, React.js, Node.js

**Why:** Provides a consistent JavaScript-based stack for building the frontend, backend, APIs, and database layer.

---

## 2. Node.js + Express.js

**Why:** Provides a lightweight backend for REST APIs, authentication, document processing, database operations, and external API integration.

**Alternatives:** FastAPI, Django, NestJS

---

## 3. MongoDB

**Why:** Provides flexible document-based storage for users, document metadata, and application data.

**Alternatives:** PostgreSQL, MySQL

---

## 4. JWT

**Package:** `jsonwebtoken`

**Why:** Provides stateless authentication for protected API requests.

**Alternative:** Session-based authentication

---

## 5. Multer

**Why:** Handles document uploads through `multipart/form-data`.

---

## 6. Document Parsing

**Libraries:** `pdf-parse`, `mammoth`

**Why:** Extract text from PDF and DOCX documents for RAG processing.

---

## 7. LangChain

**Why:** Provides components for document processing, embeddings, retrieval, and LLM integration.

**Alternatives:** Direct API integration, custom RAG implementation

---

## 8. Google Gemini

**Why:** Generates natural-language responses using the user's query and retrieved document context.

**Alternatives:** OpenAI, Anthropic, open-source LLMs

---

## 9. FAISS

**Package:** `faiss-node`

**Why:** Provides efficient vector similarity search for retrieving relevant document chunks.

**Alternatives:** Pinecone, Chroma, Weaviate

---

## 10. React.js

**Why:** Provides a component-based approach for building the interactive frontend.

**Alternatives:** Vue.js, Angular

---

## 11. Tailwind CSS

**Why:** Enables rapid and consistent UI styling using utility classes.

**Alternatives:** Bootstrap, Material UI, custom CSS

---

## 12. React Router

**Package:** `react-router-dom`

**Why:** Handles client-side navigation between application pages.

---

## 13. Git & GitHub

**Why:** Git provides version control, while GitHub provides repository hosting and collaboration.

---

## 14. Postman

**Why:** Used to test and debug REST APIs independently from the frontend.
